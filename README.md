# EAT YOUR ECHO — 내 잔상을 먹어라

8초마다 되살아나는 과거의 나를 시간 균열로 유인해 포획하는 네온 시간 루프 생존 게임입니다.

## 실행

이 저장소의 `index.html`을 브라우저로 열거나, 정적 웹 서버로 실행하세요.

```sh
npx serve .
```

## 조작

마우스 또는 손가락으로 이동합니다. 금색 시간 균열을 통과해 동선을 기록하세요. 8초 후 과거의 내가 같은 길을 반복하다 균열에 포획됩니다. 기록되지 않은 잔상과 닿으면 게임 오버입니다.

게임 설계와 제출 계획은 [PLAN.md](PLAN.md)에서 확인할 수 있습니다.
