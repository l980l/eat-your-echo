# CHECKBEAT

> One move. One beat. Survive the board.

**CHECKBEAT**은 박자에 맞춰 적 기물들이 동시에 다가오는 무한 체스 생존 게임입니다. 적이 움직인 뒤 한 번 이동하고, 적을 잡았다면 같은 박자 안에서 계속 연속 이동할 수 있습니다.

Play: https://l980l.github.io/eat-your-echo/

## 플레이 방법

1. 적 기물이 움직이면 빛나는 이동 칸이 열립니다.
2. 한 칸을 터치하거나 클릭해 이동합니다.
3. 적을 밟아 잡으면 추가 이동을 얻습니다. 연속 경로는 무지개색 선으로 표시됩니다.
4. XP를 모아 나이트, 룩, 비숍 중 하나로 승진하세요.
5. 적 기물이 내 칸에 도달하면 체크메이트입니다.

시작 기물인 폰은 예외적으로 8방향 한 칸 이동할 수 있습니다. 적 폰도 같은 규칙을 사용합니다.

## 난이도 흐름

- 시작 구간에는 폰만 등장하며, 첫 3박자는 안전 구간입니다.
- 첫 승진 후 나이트, 두 번째 승진 후 룩, 세 번째 승진 후 비숍이 적으로 해금됩니다.
- 내 이동이 끝나면 0.45초 뒤 적 기물이 동시에 움직입니다.

## 개발자 모드

시작 화면의 `DEV MODE · TEST TOOLS`를 켜면 테스트 도구가 나타납니다.

| 기능 | 버튼 / 키 |
| --- | --- |
| 즉시 승진 XP 획득 | `[1] +XP` |
| 인접한 폰 생성 | `[2] +PAWN` |
| 즉시 적 박자 실행 | `[3] BEAT` |
| 게임 속도 1× / 2× 전환 | `[4] ×2 SPEED` |

`D` 키로 개발자 도구 표시를 숨기거나 다시 열 수 있습니다.

## 로컬 실행

별도 빌드 과정이나 의존성이 없습니다. 정적 서버로 실행하세요.

```sh
npx serve .
```

그 뒤 표시된 로컬 주소를 브라우저에서 열면 됩니다.
