# EAT YOUR ECHO — 내 잔상을 먹어라

빛을 먹어 성장한 뒤, 8초마다 되살아나는 과거의 나를 흡수하는 네온 시간 루프 생존 게임입니다.

## 실행

이 저장소의 `index.html`을 브라우저로 열거나, 정적 웹 서버로 실행하세요.

```sh
npx serve .
```

## 조작

마우스 또는 손가락으로 이동합니다. 빛을 먹어 성장하고, 자신보다 충분히 작은 보라색 잔상을 흡수하세요. 큰 붉은 잔상과 닿으면 게임 오버입니다.

게임 설계와 제출 계획은 [PLAN.md](PLAN.md)에서 확인할 수 있습니다.
